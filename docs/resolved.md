### ~~PDOC-QA-010: MDX markup emits React hydration/property errors on docs pages~~
**Resolved**: 2026-08-23 (branch: react-hydration)
**Description**: Fixed React console errors surfaced by production QA (originated as a production-QA finding on the untriaged 2026-08-08 QA branch, re-filed twice before triage into the inbox). Two defects: (1) the "What's Next" card grids in `docs/hub-api.md` and `docs/macos-target.md` used HTML `class=` attributes, but `.md` files are JSX-processed by MDX, so React logged `Invalid DOM property 'class'. This will cause a hydration error.` — replaced the `<p>` with a `<div className="docs-quickstart__row">` wrapping the text in a `<span>`, preserving the logo `<img>` (`alt=""`/`aria-hidden`) and the bold "Before you start:" content. Renamed the `.docs-quickstart p` flex selector to `.docs-quickstart__row` in `src/css/custom.css` (surgical rename to keep the callout layout identical). Verified `grep -rn 'class="' docs src | grep -v className` returns nothing; build + typecheck pass; built HTML confirms `.docs-quickstart` no longer contains a nested `<p>` and card grids render `class="card-grid"`.
